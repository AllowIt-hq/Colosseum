# AllowIt

AllowIt gives agents bounded spending authority through owner-approved policies and Solana vaults. The owner retains signing authority and recovery controls.

[Architecture](docs/architecture.md) · [Product](docs/product.md) · [Commands and API](docs/api.md) · [Evidence](docs/evidence.md) · [Roadmap](docs/roadmap.md) · [Repositories](repos/README.md)

This repository contains the Colosseum report and pinned public source repositories. Initialize them with:

```sh
git clone --recurse-submodules https://github.com/AllowIt-hq/Colosseum.git
```

For an existing checkout:

```sh
git submodule update --init --recursive
```

Start with the [SDK](repos/AllowIt-hq--allowit-sdk/README.md) and [CLI](repos/AllowIt-hq--allowit-cli/README.md). Use the [submission checklist](docs/completion-guide.md) for the event, team and demo material.
